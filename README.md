# Lucky Student Wheel – วงล้อสุ่มนักเรียน (โรงเรียนบ้านไร่)

ไฟล์เดียวเปิดใช้ได้เลย ไม่ต้องติดตั้งอะไร

## ไฟล์
- `index.html` – หน้าวงล้อ (สีสดใส เสียงหมุน/เสียงปรบมือ/พลุกระดาษ)
- `students.js` – รายชื่อนักเรียน 92 คน (เฉพาะ ชั้น / เลขประจำตัว / คำนำหน้า / ชื่อ / นามสกุล)

## วิธีใช้
- กด **หมุนวงล้อ**, **Space** หรือคลิกกลางวงล้อ
- **⚙ (หรือกด S)** ซ่อน/แสดงตั้งค่า • **⛶ (หรือกด F)** เต็มหน้าจอ • **🔊 (หรือกด M)** เปิด/ปิดเสียง
- เลือกชั้นได้หลายชั้น, ติ๊กคนที่ไม่มาเพื่อตัดออกจากวงล้อ, เปิด/ปิดโหมดไม่สุ่มซ้ำ

## ขึ้น GitHub Pages
1. สร้าง repo แล้วอัปโหลดไฟล์ทั้งหมด
2. Settings → Pages → Branch: `main` / `/ (root)` → Save
3. เปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

> ⚠️ `students.js` มีชื่อ-นามสกุลเด็ก แนะนำให้ตั้ง repo เป็น **Private** (GitHub Pages แบบ private ต้องใช้แพ็กเกจที่รองรับ) หรือใช้ชื่อเล่นแทนชื่อจริงก่อนอัปโหลดแบบ Public

## อัปเดตรายชื่อ
